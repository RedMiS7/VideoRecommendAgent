# 每日推荐、CLI 与 API

## What was added

每日生成最多 5 条学习视频推荐，采用标题/元数据初筛、字幕检索与模型排序。
主题匹配为主，统计热度仅占筛选综合分的 10%。评论只使用数量。
最近 168 小时推荐过的视频不重复；同日成功且非空的任务返回已有清单，数据库原子认领防止并发执行。
空清单允许再次执行搜索与推荐，包括旧版本保存的成功空清单，无需清理数据库。
元数据请求失败时显示 HTTP 状态码；因时长未知而无法验证时长上限的候选，显示排除数量。

提供偏好、反馈、记忆、推荐查询、点击跳转 API。多分 P 视频只分析第 1 P。
搜索失败可用缓存候选；模型失败保存失败状态，不生成伪造推荐理由。

## Why it exists

无需用户每天发起对话，也能根据持久化目标主动生成学习清单。
历史记录控制跨天重复，字幕证据让推荐理由可核查，本地跳转采集最小可用行为信号。
空结果不应阻止搜索恢复后的重试；排除原因帮助区分搜索没有结果与候选无法满足硬约束。

## How to test or use it

```powershell
uv run video-agent recommend
uv run video-agent recommend --date 2026-10-01
uv run video-agent serve
uv run video-agent demo --days 8
uv run pytest tests/test_recommender.py tests/test_api.py -q
```

`--date` 仅查询已有任务，不补生成过去的推荐。API 默认监听 `127.0.0.1:8000`。
使用 `/docs` 测试以下接口：

| 接口 | 作用 |
| --- | --- |
| `GET/PUT /profile` | 查看或替换配置 |
| `POST /profile/draft` | 生成待确认配置 |
| `POST /feedback` | 提交 `{bvid, text}` |
| `GET /memory` | 查看记忆与反馈 |
| `POST /recommendations/run` | 生成或返回当天清单 |
| `GET /recommendations?date=YYYY-MM-DD` | 查询任务及结果 |
| `GET /click/{bvid}` | 记录点击并跳转 |

CLI 清单的点击路径需配合正在运行的本地 API 使用。API 查询时返回完整本地点击 URL。
硬时长限制无法验证时排除该候选；候选不足返回少于目标条数并说明原因。
中断后未释放的任务认领保留一小时，再次执行可以重试；已有非空成功清单不会因新反馈当日重写。
若此前结果为 0 条，修复搜索或配置后重新运行 `uv run video-agent recommend` 即可重试。
回归测试覆盖空清单后的搜索恢复，以及恢复后非空清单的同日复用。

2026-10-02 真实复测：搜索得到 21 个 BV 候选，但元数据请求失败，候选时长未知，
在已配置时长上限的情况下全部被排除。单独探测捕获到 B 站 HTTP 412。
因此本次已验证空清单能够重新搜索，尚未验证真实推荐生成非空清单。
若遇到同样情况，先确认本机浏览器能正常访问 B 站，待接口恢复后重新运行；不要连续高频重试。
